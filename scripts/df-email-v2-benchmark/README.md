# Email V2 benchmark — source and build

Builds the three V2 benchmark emails (B01 invitation, B02 completion, B03 M06 BLDR introduction), their six renders, the contact sheet, and the review ZIP. These are review compositions, not production send HTML.

## Rebuild

```bash
python3 scripts/df-email-v2-benchmark/prepare_assets.py   # plates, fonts, crops, B02 slab
node scripts/df-email-v2-benchmark/render.mjs             # 3 desktop + 3 mobile at 2x
python3 scripts/df-email-v2-benchmark/qa_copy.py          # writes docs/.../email-v2/qa/V2_COPY_QA.json
python3 scripts/df-email-v2-benchmark/package.py          # contact sheet, MANIFEST, ZIP, verification
```

`render.mjs B02` renders one email. Output goes to `/tmp/SITE00_EMAIL_V2_BENCHMARK/` and the ZIP to `/tmp/SITE00_EMAIL_V2_NDX_BENCHMARK.zip`.

## Inputs

- Plates DF-I01, DF-I02, DF-I03 from `/tmp/df-email-assets/` or release `df-v2-mass-cj-2026-10-11`.
- Saira Semi Condensed 400–700, downloaded into `source/fonts/` (not committed).
- Brand authority image at `/tmp/df-email-assets/AUTHORITY.jpg`, checked against its SHA-256 before packaging.

No step calls OpenArt or sends email.

## Layout

| Path | What it is |
|---|---|
| `source/base.css` | Type, palette, review stage, shared mobile rules |
| `source/B0*.html` | One responsive file per email; desktop and mobile come from the same file |
| `source/art/b03_plan_*.svg` | Hand-drawn illustrative plans for B03 |
| `source/assets/` | Crops and the B02 slab, generated by `prepare_assets.py` |
| `qa_copy.py` | Uppercase, customer language, rhetoric, repetition, variety, alt text, contrast |
