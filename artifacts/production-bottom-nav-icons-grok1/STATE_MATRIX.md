# State matrix

| State | Glyph ink | Red | Label | Underline |
|-------|-----------|-----|-------|-----------|
| Inactive | `#141414` structure, `#8d8d93` support lines | None inside the glyph | Existing gray/black | None |
| Active | Structure stays black | Signature accent only (`#eb1c24`) | Existing red | Existing red underline |
| Inbox unread | Envelope unchanged | Overlay dot (host) or count (mobile) | Unchanged | Unchanged |
| Activity | Timeline unchanged | Overlay dot, separate from the terminal node | Unchanged | Unchanged |
