# THE EXCHANGE — Release Changelog, baseline LL-01–LL-74 → revised S1-01–S1-86

> **NONCANONICAL. PROPOSED — NOT APPROVED.** A development proposal for THE EXCHANGE. It changes no canon, no approval record, no repository and no production system.

**PROPOSED — NOT APPROVED.** Every one of the 74 baseline releases, with its disposition. Nothing was appended automatically, nothing was silently removed, and no release is coded G (redundant).

### Disposition counts

| Code | Meaning | Releases |
|---|---|---|
| A | Unchanged | 54 |
| B+F | Incorporates an exchange and needs more time | 10 |
| B | Incorporates an exchange | 6 |
| A (line edit) | Unchanged except one continuity line | 1 |
| C | Replaced | 1 |
| D+E | Combined and moved | 1 |
| E (date only) | Moved (fictional day only) | 1 |
| NEW | Added | 12 |

**Why 86 and not 74.** 74 baseline releases − 1 replaced in its slot (LL-28 → Both Stations) + 12 additions = 86. Two scenarios (One Dance, Owed and Fourteen Hundred Hats) fold entirely into existing releases. The other eight add releases: PX-02, PX-04, PX-06 and PX-07 add two each (one where the request is made, one where it plays out, because a request needs time to travel); PX-03 adds one and takes LL-28's slot for its first; PX-01, PX-09 and PX-10 add one each (PX-09 also rewrites LL-33). A lean alternative of about 81 releases is on the decision board.
