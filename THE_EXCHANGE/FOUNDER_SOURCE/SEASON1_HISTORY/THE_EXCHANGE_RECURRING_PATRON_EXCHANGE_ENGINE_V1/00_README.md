### IDs

- **LL-nn**: baseline hybrid release (74). **S1-nn**: revised release (86).
- **PX-nn**: selected exchange scenario (10). **C-nn**: candidate (20).
- **LV-1 to LV-4**: the Living Legacy visions, unchanged.
- **GE−n / GE+n**: fictional day relative to the Grand Exchange (GE0, a Saturday).

### What this package did not do

It did not modify the Series Bible, the approval matrix or canon; did not commit to GitHub or open a pull request; did not change Supabase records or SITE 00 production systems; did not generate character visuals or wardrobe images; did not launch SHAW; did not create brand partnerships; and does not assume the founder has approved the hybrid. Season 2 was not developed.
