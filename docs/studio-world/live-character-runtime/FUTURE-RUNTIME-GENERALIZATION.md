# Future Runtime Generalization

Character runtime is the **first vertical slice**. The adapter/manifest/host pattern must not block:

```
Character assembly
    → World assembly (e.g. Astréa)
    → Set assembly
    → Product / object assembly (e.g. mannequin)
    → Shared capture department
```

## Preserved extension points

- Versioned assembly manifests per domain
- Runtime host registry (not localhost-only types)
- Capture service + rig presets per asset class
- Command protocol namespaces (`command` prefix or domain field in v2)

## Explicitly not built

Astréa runtime, world assembly, Frontal Slayer mannequin, set assembly, product assembly — **architecture only** in this sprint.
