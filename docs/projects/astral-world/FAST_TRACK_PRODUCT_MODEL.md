# Astral World — Fast Track Product Model

**Status:** Prototype · CREATIVE_EXPLORATION / FOUNDER_FAST_TRACK

---

## Product thesis

Astral World is a **digital place people enter**, not a website about tarot.

## Experience loop

```
ENTER ASTRAL WORLD → ENTER DISTRICT → SEE WHO IS HERE → CHOOSE WHAT TO DO
→ VISIT DESTINATION → INTERACT → RECEIVE READING → SAVE JOURNEY → RETURN
```

---

## Hierarchy

```
ASTRAL WORLD (master universe)
  └── ASTRÉA (flagship district)
        ├── Tarot Suite (deep / private / intentional)
        ├── Astral Mall (fast / spontaneous / quick)
        └── Coffee Shop (conversation / comfort / community)
```

Future districts remain structurally possible.

---

## Destination roles

| Destination | Role | Signature interactions |
|-------------|------|------------------------|
| Tarot Suite | Premium private readings | Enter Suite, Choose Reader, Join Wait |
| Astral Mall | High-frequency quick reads | Pick a Kiosk, Start Quick Read, Join Wait |
| Coffee Shop | Social hub | Join Her Table, View People, Leave Table |

---

## Social product

Presence + Places + Shared Activities — not a feed.
