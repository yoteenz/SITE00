# Commission eligibility matrix

| Event | Creates paid conversion? | Creates commission eligibility? |
| --- | --- | --- |
| Referral link visit | No | TRACKED / attribution touch only |
| Intake started | No | May strengthen attribution evidence |
| Intake completed | No | Not payment evidence |
| Quote accepted | No | Not payment evidence |
| Checkout session created | No | Not payment evidence |
| Checkout redirect / client “success” UI | No | Not payment evidence |
| **Verified server-side payment** for **$500 base package** | **Yes — paid conversion** | **NOT YET ELIGIBLE** until 14-day hold |
| 14 days after verified payment, no disqualifying refund | — | **ELIGIBLE** (pending founder approval) |
| Founder approval | — | **APPROVED** for payout cycle |
| External payment recorded | — | **PAID** |

## Disqualifiers (no commission)

- Self-referral, duplicate referral, failed attribution window, existing-client repeat-only rule, related-party unresolved, insufficient payment evidence, full refund before payout (unpaid commission reversed).

## Holding period

**14 days** from **verified payment timestamp**. Clock does not start on visit or intake completion.
