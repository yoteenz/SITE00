# Design archetype map

Distinct archetypes: **13**.

- `INVITATION`: `personal-foundation-invitation`
- `INTAKE_PROGRESS`: `intake-started`, `intake-completed`
- `QUOTE_AND_ACCEPTANCE`: `quote-ready`, `quote-updated`, `quote-accepted`
- `CHECKOUT_AND_PAYMENT`: `checkout-link-ready`, `payment-confirmed`, `payment-failed`
- `PROJECT_ACTIVATION`: `project-activated`
- `COMPLETION`: `foundation-complete`
- `RECORDS_AVAILABLE`: `records-available`
- `ACTION_REQUIRED`: `client-action-required`
- `APPROVAL`: `approval-requested`, `approval-completed`
- `PROGRESS_AND_OPPORTUNITY`: `foundation-credit-issued`
- `BLDR_JOURNEY`: `bldr-discovery`, `M06`
- `EDITORIAL_EDUCATION`: `M01`
- `POST_COMPLETION_JOURNEY`: `M13`

Each template also has its own layout key so shared archetypes are not the same composition.
