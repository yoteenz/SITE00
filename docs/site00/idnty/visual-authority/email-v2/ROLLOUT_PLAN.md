Twenty desktop and twenty mobile compositions, forty renders, with two visual QA cycles each. Asset reuse map updated so no crop is repeated across emails in the same sequence.

## Gate 4 — HTML translation (separate authorization)

Table-based HTML, inline styles, PNG exports of SVG art, dark-mode checks, client testing. Not authorized in this sprint.

## What must hold throughout
