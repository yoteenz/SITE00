## Known limitations
- Project artwork, atrium plate and 3D pipeline objects are slots (`ASSET_SLOTS.json`, generated by `scripts/generate-dws-asset-slots.ts`). Pipeline objects render interim live-SVG FORMS (9 forms) until the 3D renders are registered.
- Seeded NDXBOOK content; decisions persist device-locally. No backend/data wiring (by instruction).
- Mobile featured-board copy is clipped at 390px (dense authority); Opus convergence item. Tablet portrait overlays float the modal over the split drawer | inspector.
- A page *reload* in the local dev harness throws a pre-existing `removeChild` error on other Production routes too; persistence was verified across a fresh page load.
