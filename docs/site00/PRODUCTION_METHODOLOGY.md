# SITE 00 Production Methodology

SITE 00 operates around a broad production methodology. These stages represent **how we think about brand and production work** — they are **not** universal launch requirements.

## Stage Flow

```
IDEA → FOUNDATION → IDENTITY → WORLD → DIGITAL → COMMUNICATION → SOCIAL → CONTENT → CAMPAIGN → LAUNCH → EVOLVE
```

| Stage | Purpose |
|-------|---------|
| IDEA | Initial concept and opportunity |
| FOUNDATION | Business and project foundation |
| IDENTITY | Brand identity and positioning |
| WORLD | Brand world and creative universe |
| DIGITAL | Digital product and platform |
| COMMUNICATION | Communication systems (email, messaging) |
| SOCIAL | Social presence and assets |
| CONTENT | Content production |
| CAMPAIGN | Campaign and launch creative |
| LAUNCH | Launch execution |
| EVOLVE | Post-launch evolution |

## Key Principle

A project may:
- Skip a stage
- Defer a stage to post-launch
- Complete only part of a stage
- Add custom workstreams
- Have multiple releases or launch milestones
- Use a completely custom launch definition

**Launch readiness is calculated against the project's approved current target — not against all possible capabilities.**

## Examples

| Project Type | May Launch Without | May Require |
|--------------|-------------------|-------------|
| Trucking services (AIO) | Social, native app, campaigns | Website, auth, payments, load board |
| Luxury brand (Frontal Slayer) | Future education seasons | Commerce, campaign hero, analytics |
| Platform (SITE 00) | Expanded marketing automation | Admin ops, builder, studio workflow |
