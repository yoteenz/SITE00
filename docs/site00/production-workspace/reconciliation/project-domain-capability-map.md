# Project × domain capability map

`GLOBAL_TAB_AVAILABLE ≠ PROJECT_DOMAIN_ESTABLISHED.` Every project shows seven tabs. Whether a work domain is
**established** is derived from the project's own graph (≥ 1 node in the domain). The declared applicability documents
where a domain is expected — it never invents one. Source: `shared/site00-production-graph/capabilities.ts`;
generated: `project-domain-capability.json`.

HUB, INBOX, LIBRARY and ACTIVITY apply to every project (they project whatever the graph holds, empty included).

Applicability vocabulary: `PRIMARY` (the domain is the project's main production surface) · `APPLICABLE` (expected) ·
`CONDITIONAL` (only when explicitly established) · `NOT_APPLICABLE`.

What would establish a domain (`DOMAIN_ESTABLISH_HINT`, shown verbatim in every empty state):

- **DESIGN** — "Design becomes available when a site, page family or visual authority is recorded for <PROJECT> — a family
  production contract or a visual-authority package."
- **EXPERIENCE** — "Experience becomes available when a world, zone, environment, scene or spatial interaction system is
  recorded for <PROJECT>."
- **EXPRESSION** — "Expression becomes available when a campaign, editorial system, casting workflow or other expression
  production node is created for <PROJECT>."
