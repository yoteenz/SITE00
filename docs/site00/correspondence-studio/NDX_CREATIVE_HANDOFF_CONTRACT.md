# NDX creative handoff contract

NDX discipline transfers to email without copying one visual style.

Each campaign handoff must define:

- Intention and audience
- Central idea and editorial strategy
- Visual direction and narrative rhythm
- Meaningful primary action
- Per-email editorial purpose (no generic three-section auto-layout)

Type: `NdxCreativeHandoff` in `shared/site00-correspondence-studio/types.ts`.

Opus Email V2 authority docs are the current Digital Foundation reference:

- `docs/site00/idnty/visual-authority/email-v2/authority/NDX_METHODOLOGY_RECOVERY.md`
- `docs/site00/idnty/visual-authority/email-v2/authority/EDITORIAL_VOICE_SYSTEM.md`
- `docs/site00/idnty/visual-authority/email-v2/authority/COMPOSITION_AUTHORITY.md`

Creative authority overrides generic template convenience. Shared components are allowed; shared full-page compositions are not mandatory.
