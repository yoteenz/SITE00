# Existing Location — Service Flow

```
EXISTING LOCATION entry
  → What do you need? (request type)
  → Platform (+ optional site URL)
  → Describe issue / enhancement + evidence
  → Access setup (delegated — no primary passwords)
  → Diagnosis (SITE 00)
  → Findings + recommended intervention
  → Scope + quote (diagnosis-based)
  → Client approval
  → Checkout (payment or courtesy comp)
  → Intervention (staging-first default)
  → QA / validation
  → Completion record + audit trail
```

**Safety default:** diagnose-only or diagnose-then-authorize; no production modification before approval + commercial authorization (except explicit founder override).
