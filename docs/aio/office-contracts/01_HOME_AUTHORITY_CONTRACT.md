| Honest state | When | The surface shows |
|---|---|---|
| AVAILABLE | every source of the region is backed | the items, newest / most urgent first |
| PARTIAL | some sources are connected, others are not | the connected items plus a short “not connected yet” line naming each missing source — never a zero for an unconnected source |
| NO_DATA | connected and genuinely empty | a plain “nothing here” line with when it was last checked |
| NO_ACCESS | the actor lacks the grant for a source | nothing from that source and no count that would reveal it |

| BLOCKED | a dependency is missing (state, role, model, table) | the dependency by name, linked to its gap |
| COMING_LATER | deliberately deferred to a named sprint | the sprint it waits on |
| ERROR | a source failed to load | which source failed and a retry; other regions keep working |

**Action ownership rule**

| Root | Its actions |
|---|---|
| HOME | routes to actions (ROUTE only) |
| WORK | executes service production (EXECUTE) |
| REPORTS | reviews history and analysis (REVIEW, ROUTE) |
| MORE | administers supporting business systems (ADMINISTER) |

- An action changes state only in the root that owns that state: production roots execute, entry roots onboard, administration roots administer supporting systems.
- A projection root only ROUTES to the owner; an oversight root only REVIEWS or ROUTES. Neither executes.
- An action shown away from its owner is a link to the owner’s action, never a second copy of it.
- Every action names the existing permission or privileged act that gates it; a contract never broadens a permission.
- No root silently mutates another root’s canonical state: an action that changes state is declared by the root that owns it.
