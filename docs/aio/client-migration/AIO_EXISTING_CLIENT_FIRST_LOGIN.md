## Review interaction

Each section: LOOKS_RIGHT · NEEDS_AN_UPDATE · NOT_SURE. A correct section needs one tap; field-by-field editing only opens for NEEDS AN UPDATE. I’M NOT SURE never blocks — it becomes an AIO follow-up.

Client review states: NOT_STARTED · REQUIRED · IN_PROGRESS · COMPLETE.

## Confirmation gate

Before: **CLIENT_CONFIRMATION_REQUIRED**. The founder sees PROFILE PREPARED · MIGRATION REVIEW COMPLETE · INVITATION SENT · CLIENT CONFIRMATION PENDING. The client does not count as active.

Final action: **CONFIRM & ENTER MY OFFICE** → ACTIVE, with CLIENT_CONFIRMED + CLIENT_ACTIVATED events.
