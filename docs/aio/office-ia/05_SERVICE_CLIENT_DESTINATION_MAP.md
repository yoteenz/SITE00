## Contextual expansion rule → Brain mechanism

| Founder rule | Kind | Enforced by |
|---|---|---|
| relevant | SUGGEST_ONLY_WHEN | ExpansionRule when_active_any + requires (signal conditions) must match the client; NO_MATCHING_RULE otherwise |

| explainable | SUGGEST_ONLY_WHEN | ExpansionRule.reasons + grounded_in; every evaluation carries reasons and its rule id |
| non-intrusive | SUGGEST_ONLY_WHEN | PLACEMENT_NOT_ALLOWED — only approved placements |
| actionable | SUGGEST_ONLY_WHEN | ExpansionRule.cta (label + action) |
| truthful | SUGGEST_ONLY_WHEN | MISLEADING · CONFLICTING_SERVICE_STATE suppress |
| already active | SUPPRESS_WHEN | ALREADY_OWNED |
| unavailable | SUPPRESS_WHEN | SERVICE_UNAVAILABLE |
| not applicable | SUPPRESS_WHEN | NOT_APPLICABLE |
