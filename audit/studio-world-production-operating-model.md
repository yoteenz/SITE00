# Studio World Production Operating Model

**Audit:** P0.5 Production Methodology + Automation Assurance  
**Date:** 2026-08-23  
**Status:** Hypothesis — challenged by forensic audit

---

## Executive Verdict

Studio World is **not yet a coherent production operating system**. It is a **constellation of sophisticated pipelines** with strong contracts in creative lineage, concept hierarchy (post-Experiment F), and visual-development-before-implementation — but **missing medium-native stages**, **missing invalidation logic**, and **missing bridges** between approved proofs and full production (especially site-wide implementation and product behavior).

P0 solved **execution truth** (persistence). P0.5 finds the **factory process itself is incomplete and partially mis-sequenced**.

---

## Recommended Meta-Model (Modified Hypothesis)

```
INTELLIGENCE
  → READINESS (commercial + module gates)
  → FORMATION (medium-specific concept)
  → DISTINCTIVENESS / VALIDATION
  → DIRECTION (where applicable — not all mediums)
  → EXPRESSION SYSTEM
  → MEDIUM SYSTEM (IA, behavior, motion, topology as required)
  → DEVELOPMENT (visual, copy, assets)
  → REVIEW (founder + automated gates)
  → PRODUCTION CONTRACT
  → IMPLEMENTATION / GENERATION
  → EVALUATION (fidelity, adherence, performance evidence)
  → REVISION (surgical, scoped)
  → PRODUCTION PROMOTION
  → LEARNING (evidence ≠ canon)
```

### Shared stages (all mediums)

| Stage | Meaning |
|-------|---------|
| **INTELLIGENCE** | Durable brand/business/founder context scoped to project |
| **READINESS** | Honest gates — what is allowed to start |
| **FORMATION** | Create medium-native concepts (not assets) |
| **DISTINCTIVENESS** | Prevent collapse / duplication / generic output |
| **REVIEW** | Founder judgment at consequential boundaries |
| **PRODUCTION CONTRACT** | Compiled artifact binding implementation |
| **EVALUATION** | Verify output against contract (NOT_EVALUATED when unproven) |
| **REVISION** | Scoped change without full regeneration |
| **LEARNING** | Capture performance/preference evidence without canon promotion |

### Medium-specific divergence

| Medium | Extra stages | Skips |
|--------|--------------|-------|
| **Identity** | Identity System compiler, guidelines | World Expression |
| **Content** | Topic strategy, campaign, calendar, sequence | Implementation contract (usually) |
| **Site** | Site architecture, page families, IA, SEO | — |
| **Experience** | Interaction/behavior architecture | Full site IA (should not own) |
| **Product** | Role/workflow/state/permission models | Visual metaphor as primary |
| **Motion** | Motion grammar, reduced-motion contract | Most visual-dev path initially |
| **World** | Topology, systems, presence, economy blockers | Everything until P3 research complete |

---

## Critical Methodology Corrections (P0.5A)

1. **Site:** Insert **Site Architecture → Page Families → Layout Grammar** between approved hero proof and Composer.
2. **Experience:** Split **behavior/IA** from **visual development**; stop using Experience Expression as site architecture solver.
3. **Identity:** Add **Identity Concept Territory** before direction/style production.
4. **Content:** Add **content planning engine** upstream of concept formation.
5. **Invalidation:** Implement formal dependency graph — upstream changes must supersede or mark stale downstream artifacts.
6. **Product:** Define Product Expression boundary (P2) — do not implement yet.

---

## What NOT to Build Yet

- World Formation runtime
- Product Expression implementation
- Multiplayer / avatars / economy
- Autonomous canon promotion
- Full cost ledger (foundation exists)
- Broad client automation without live verification
