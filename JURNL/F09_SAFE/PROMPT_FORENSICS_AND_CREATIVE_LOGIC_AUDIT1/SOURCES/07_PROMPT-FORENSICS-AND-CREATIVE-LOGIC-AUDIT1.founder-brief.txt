==================================================
CONVERSATION CONTEXT / WHY THIS SPRINT EXISTS
==================================================

JURNL F09 SAFE TO SPEND has gone through multiple rounds of:

- concept development
- creative-direction correction
- composition-blueprint correction
- render-ownership correction
- hybrid composite execution
- three-concept rerun
- visual implementation correction

Yet the visual results are still repeatedly missing the founder’s intended quality bar.

Observed failures include:

- outputs feel generic
- Mediterranean identity is weak
- environmental richness is missing
- compositions feel assembled rather than authored
- scene plates become the design instead of supporting it
- deterministic UI is technically correct but visually crude
- text glitches or feels pasted-on
- concepts feel unfinished
- three concepts collapse into variants rather than genuinely distinct authorities
- generated backgrounds are treated as finished visual thought
- authority images are under-consumed
- “reference fidelity” language does not consistently produce reference-level richness
- implementation prompts over-index on mechanics and under-index on visual authorship
- mobile viewport instructions have sometimes been misread as phone/device rendering
- successive corrective prompts have accumulated constraints that may now be contradicting each other

The founder now believes the actual problem may be upstream:

THE PROMPTS THEMSELVES MAY BE LOGICALLY INCOMPLETE, CONTRADICTORY, OVER-CONSTRAINED, OR OPERATING AT THE WRONG ABSTRACTION LEVEL.

This sprint exists to audit the prompt system itself before another visual attempt is made.

==================================================

DO NOT GENERATE ANY NEW JURNL IMAGE.

==================================================
KNOWN FAILURE THAT CAUSED THIS
==================================================

The current JURNL F09 prompt stack evolved incrementally.

Each corrective sprint added more constraints:

- territory separation
- brand expression
- composition blueprints
- render ownership
- deterministic UI
- plate generation
- contamination guards
- exact product truth
- anti-template rules
- device-chrome prohibitions
- authority-fidelity rules
- founder-review contracts

This may have created a prompt system that is technically thorough but creatively self-defeating.

The prompt may now be:

TOO CONSTRAINED TO CREATE
TOO VAGUE TO ART DIRECT
TOO TECHNICAL TO COMPOSE
TOO SPLIT ACROSS LAYERS TO FEEL COHERENT

This sprint must determine whether that is true.
