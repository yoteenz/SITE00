# 10 · Visual authority comparison

The founder's V9 DOT 01 package (37 authorities) and the micro-asset Batches 01–04 were searched for:

- an open context menu or overflow menu;
- a rename surface;
- a delete confirmation;
- an overflow / more glyph.

**None is drawn.** Every new state below is assembled from existing authority parts. No image was generated, no artwork was invented and no paid provider was used.

| New state | Built from (authority / asset) | Matches | Departs (founder review) |
|---|---|---|---|
| MANAGE POCKET chip | the Pocket page's own BACK chip (02–05): torn paper tile, ink line glyph, shadow, chip row geometry | tile, size, row, shadow | a three-dot ink glyph drawn in the chip line set: no engraved "more" glyph exists |
| MANAGE POCKET menu | JURNL_POPOVER (previous sprint): `F05_DOT01_14_LARGE_PARCHMENT_SHEET` 9-sliced, Authority Serif, gold rule, square-rounded parchment buttons, terracotta for the destructive item | parchment, serif, gold detail, square-rounded, no glass | no authority draws an open menu: the layout is a **proposal** |
| RENAME POCKET | the DOT 01 overlay pattern of 12 / 14 / 25: SK03 FIELD, seal + heading paper with cursive subtitle, one torn sheet with field rows and the action pair | environment, heading, sheet, fields, buttons | the screen itself is not drawn; the copy (CURRENT NAME / POCKET NAME / SAVE NAME) is from the sprint brief |
| DELETE THIS POCKET? | authority **25** ARCHIVE ACCOUNT: same overlay, rows and confirm / keep pair | composition, rows, button order | title, alert and button words follow the sprint brief (DELETE THIS POCKET? / CONFIRM DELETE / KEEP POCKET) |
| DELETE POCKET (blocked) | authority **36** ARCHIVE BLOCKED: alert, BLOCKERS list with lock glyphs, the keep / resolve pair | composition | title DELETE POCKET and the alert wording |
| After delete | 06 / 22 (directory and empty state) plus the existing JURNL success toast | as drawn | none |

**Verdict: NEEDS FOUNDER APPROVAL.** The surfaces reuse the authority language throughout, but the open menu, the rename screen and the delete wording have no authority to match pixel for pixel.
