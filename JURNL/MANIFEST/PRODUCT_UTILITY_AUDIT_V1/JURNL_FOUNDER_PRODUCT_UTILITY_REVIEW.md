# JURNL founder product utility review

## Headline

JURNL **can track** obligations and compute safe-to-spend locally, but it **does not yet assist** like a personal accounting tool: no subscription hub, no bill funding progress, no pay/confirm loop, and hub copy stays editorial vs factual.

## What works (preserve)

- Single device repository + projection pipeline  
- F07 upcoming timeline + add repeating charges (**Journey A verified**)  
- F09 centralized STS formula + WHY breakdown  
- Trip / purchase / goal / plan reservations (entity-level)  
- 16-family navigation intact  

## Critical gaps (P0)

1. Per-bill **set aside / remaining** (founder car insurance example)  
2. **Mark paid** + ledger linkage  
3. **Subscriptions** UX (kind, list, totals)  
4. **Plain language** on F03/F07/F08 hubs  
5. Avoid STS **double-count** when funding ships  

## Evidence in ZIP

- Journey audit + QA JSON  
- Plain language CSV (245 strings)  
- Roadmap + integrity matrix  

## Decisions required

1. Approve **funded_amount on obligation** vs **plan-only linking**  
2. Approve **F07 subscriptions panel** (no new family)  
3. Prioritize **Sprint A vs B** order  
4. Approve **functional copy** replacements (matrix) without visual redesign  

## Explicit non-goals (this initiative)

- No bank aggregation  
- No visual redesign  
- No logo/identity branch changes
