## Quality note: quantized handoff

The handoff's own README says: "PNG color was quantized so this archive fits a single download. Alpha is intact."
* All 18 files are palette PNGs (mode P).
* Their byte sizes are about a third of the manifest's RGBA `bytes` (for example OV08: 4,098,162 installed vs 11,885,148 in the
  manifest). The installed sha256 therefore differs from the original RGBA file.
* Dimensions and visible-alpha bounds (alpha > 16) match the manifest exactly for all 18 (unit A1, A2).
* If the founder wants the unquantized RGBA originals, they must be re-exported from OpenArt (history ids are in the registry).
  That is a founder action; it is not done here.
