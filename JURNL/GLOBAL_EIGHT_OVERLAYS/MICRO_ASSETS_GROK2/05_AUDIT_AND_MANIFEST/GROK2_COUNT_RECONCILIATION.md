# Count reconciliation

## What the GROK1 package was counting

Those four numbers are different kinds of count. They were never meant to be the same number.

| Figure | What it counted |
| --- | --- |
| 71 roles | Register rows. 70 provisional slots plus the light selected-bank, which the authority draws and the plan did not list. |
| 55 PNGs in `03_NEW_GENERATED` | A duplicate dump. That folder copied every icon, toggle, and paper, including comparison extracts. It is not a count of unique art. |
| 49 unique production masters | Distinct files that a ready or partial role actually pointed at. Several roles share one file, so this is lower than the role count. |
| 53 ready for review | Roles whose status was ready. Higher than 49 because the close disc, the dark bank, the calendar, and the chevron are each one file used by more than one role. |

Roles that were not a file: deduplicated slots, baked medallions, the unresolved papers, and the rejected back-arrow.
